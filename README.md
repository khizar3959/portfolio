Simply double-click `index.html` in your file explorer to open it in Chrome, Edge, or your default browser.

```powershell

```

## 🌐 Free 2-Minute Deployment Options

### Deploy to Vercel (Recommended):
1. Push this folder to a GitHub repository (e.g. `khizar3959/portfolio`).
2. Log in to [vercel.com](https://vercel.com).
3. Click **"Add New Project"** and import your portfolio repository.
4. Click **"Deploy"** — it will be live with an SSL certificate and custom URL in seconds!

### Deploy to GitHub Pages:
1. Create a repository named `khizar3959.github.io` on your GitHub account.
2. Push `index.html`, `styles.css`, and `script.js` directly to the `main` branch.
3. Your portfolio will immediately be live at `https://khizar3959.github.io/`!
